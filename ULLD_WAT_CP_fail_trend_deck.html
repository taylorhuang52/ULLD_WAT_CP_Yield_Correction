資料：ULLD_WAT_fail_count.csv、ULLD_WAT_CP_Summary_20261030.xlsx、ULLD_DataBase2025.xls（CP Detail Yield Summary）

  • 以 Lot 對應 WAT 與 CP，共 2,949 個 Lot（WAT Run 日期 2025-09-23 ～ 2026-10-09），Part No 取 PRODUCT ID 後 3 碼：03U（1892）、07U（406）、04U（346）、02U（194）、06U（57）、08U（51）

  • WAT 與 CP 測項依名稱對應成 5 類（IGSS / IDSS / BVDS·DBV / VT / VSD），對應為依命名的推定，請確認

  • VT(1mA)、IDSS(450V)、IDSS_2、IGSSF_2、IGSSR_2、IDSS(100V/200V/300V) 僅 8 個 Lot 以內有測，且這些 Lot 沒有對應的 CP 資料，在本分析的 Lot 中 fail 皆為 0

⑰ 演變過程與主要發現

  • IGSS（閘極漏電）是 ULLD 最大的 fail 來源，且 WAT 與 CP 高度相關：類型層級 Spearman 0.76（Pearson 0.54），各 Part 內 0.74–0.83。CP 的 IGSS2F@15V 約占 CP 全部 fail 的 51–53%，其次是 IDSS2@18V（35–41%）。
  • IDSS 在 2026-06 出現台階式上升：WAT 約 3.1–3.3%（2025-11～12）→ 4.4–4.7%（2026-06 起）；CP 約 2.3–2.4% → 3.1–3.4%。兩端同步上升，類型層級相關 0.56。
  • IGSS 無長期單向趨勢，呈週期性起伏：WAT 2.8–4.1%、CP 3.5–4.6%，高點出現在 2026-01、2026-03 與 2026-09，兩端同步。
  • WAT 的 VT 與 BVDS/DBV 與 CP 同類 bin 幾乎無相關（ρ 0.08 / 0.10），卻與 CP 的 IGSS / IDSS 相關（WAT VT↔CP IGSS 0.64、WAT BVDS/DBV↔CP IDSS 0.49）。另外 89% 的 Lot 中 IGSSF 與 IGSSR 的 fail 數完全相同，95% 的 Lot 中 VT(50uA) fail 數不低於 IGSSF，推測 WAT 這些項目 fail 的是同一批 site（連帶 fail）。CP 為依序分類的 bin，VT / BVDS 的 die 已先被前面的 IGSS / IDSS bin 吃掉。
  • CP 端有小幅但持續上升的項目：VT 類 bin 由 0.03–0.07%（2025-11～12）升到 0.39%（2026-09）；Contact / 電阻類 bin（含 R@5V）自 2026-08 起升到 0.10–0.13%；BVDS 類 bin 則由 2025-12～2026-01 的約 1.0% 降到 0.3–0.5%。
  • VSD：WAT VSD(1mA) 約 0.3–0.46%，CP VFSDS1@1mA 幾乎為 0，兩者無相關（ρ −0.06）。
  • Part No 差異很小：IGSS、IDSS 的趨勢在各 Part 一致（03U 占 64% Lot）；06U（57 Lots）、08U（51 Lots）的 fail rate 略低，但樣本少。

⑱ 改善建議

  1. IGSS 納入 WAT→CP 預警：WAT IGSS 與 CP IGSS2F 相關強（ρ≈0.76），可用 WAT IGSSF fail rate 建立 SPC 管制線與 CP 預期 fail 的回歸 / 門檻，WAT 異常的 Lot 可提前攔截或加強 CP 監控。
  2. IDSS 2026-06 台階上升需回查原因：兩端同時上升，較像來料或製程變化而非單純測試端問題。建議比對 2026-05～06 前後的 EPI / wafer lot、製程條件與機台維護紀錄，以及 IDSS 量測條件是否有調整。
  3. WAT fail count 改用「不重複 site」或「首個 fail 項」計算：WAT 多個測項 fail 的是同一批 site，直接加總會高估且造成 VT、BVDS 與 CP 同類 bin 看似無關。建議在 WAT 端輸出 site 層級 fail 資料，才能與 CP 的依序 bin 對照。
  4. 持續監控 CP 的 VT、Contact / 電阻類 bin：目前占比小（約 0.1–0.4%），但 2026 年中後持續上升；建議先確認是否與探針、接觸條件或規格調整有關。
  5. VSD 規格對齊：WAT VSD(1mA) 有 fail 而 CP VFSDS1@1mA 幾乎無 fail，建議核對兩端 limit 與量測條件是否一致。
  6. 補充資料以深入分群：ULLD 檔案缺 Station / Device Mapping / EPI / BGBM，目前只能以 Part No 分群，而 Part 間差異不大；若能補上這些欄位，才可進一步找出 2026-06 的 IDSS 上升與 IGSS 起伏的來源。

註：以上為資料觀察與假設，需搭配製程 / 測試 log 驗證；WAT↔CP 測項對應為依命名推定。
